# NENA-APP Backend

This is the backend server for the NENA-APP, built with Express.js and following a domain-driven component architecture.

## Structure

- `/core`: Shared infrastructure (database, cache, middleware, utils).
- `/components`: Business domain modules (auth, feed, messages, etc.).

## Getting Started

1. `cd server`
2. `npm install`
3. `npm run dev`
